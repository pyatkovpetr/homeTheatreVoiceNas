# HomeProjector — лаунчер-учебная станция для проектора

Домашний лаунчер для Android-проектора / ТВ-приставки: медиатека NAS (видео,
музыка, фото, книги), учебная станция со школьными видеоуроками, файловый
браузер с загрузками, голосовой ассистент с ReSpeaker XVF3800 и чат-бот.
ИИ по умолчанию работает через **NeuralDeep** (`https://api.neuraldeep.ru/v1`),
можно переключить на локальный сервер (Ollama / OpenAI-совместимый).

Проект развивает идеи [NASY](https://github.com/pyatkovpetr/NASY) (клиент NAS
для телефона), но работает **напрямую по SMB без промежуточного бэкенда** и
исправляет его слабые места: непрерывный плеер, живой прогресс загрузок,
правильный порядок глав EPUB, TTS без обрывов на длинных текстах, кэширование.

- Kotlin + Jetpack Compose, тёмная высококонтрастная тема, крупные плитки
- Ландшафтная ориентация, навигация пультом (D-pad), полноэкранный режим
- Лаунчер по умолчанию (категория `HOME` + `LEANBACK_LAUNCHER` для Android TV)
- minSdk 26 (Android 8.0), targetSdk 35

## Готовый APK

`ProjectorLauncher-1.2.0.apk` в корне проекта (~5 МБ, минифицирован, подписан
debug-ключом — устанавливается сразу).

```bash
adb install -r ProjectorLauncher-1.2.0.apk
adb shell cmd package set-home-activity com.homeprojector.launcher/.MainActivity
```

## Разделы

| Плитка | Возможности |
|---|---|
| **Видеотека** | Фильмы и сериалы с NAS по SMB2/3, потоковый ExoPlayer с перемоткой |
| **Учёба** | Школьные видеоуроки по предметам (подпапки NAS) + учебники во встроенной читалке, поиск |
| **Музыка** | Треки / альбомы / артисты / избранное; теги читаются из заголовков файлов (ID3v2, FLAC, MP4) без скачивания целиком; непрерывное воспроизведение с очередью и автопереходом |
| **Фото** | Сетка превью с NAS, полноэкранный просмотр свайпом, зум, оригинальное качество |
| **Книги** | Читалка PDF / EPUB / FB2 / TXT: TTS-озвучка с подсветкой и скоростью, закладки, сохранение позиции; EPUB с правильным порядком глав (OPF spine) и картинками |
| **Файлы** | Браузер всех файлов NAS, поиск по имени (debounce), скачивание, открытие по типу; кнопка перехода к локальным файлам устройства |
| **Приложения** | Сетка всех установленных приложений |
| **Ассистент** | Голос через ReSpeaker XVF3800 → Whisper → чат-бот → озвучка; отдельный экран чата |

В шапке домашнего экрана — быстрые иконки **Загрузки** (менеджер задач
SMB→устройство: живой прогресс, пауза/докачка, отмена) и **Настройки**.

## Учебная станция

Создайте на NAS папку `school` (имя меняется в настройках) с подпапками
предметов, например:

```
school/
├── Математика/      → видеоуроки (.mp4/.mkv) и учебники (.pdf/.epub/.fb2)
├── Физика/
└── Русский язык/
```

Раздел «Учёба» показывает предметы плитками; видео воспроизводятся сразу,
учебники открываются в читалке с озвучкой. Поиск ищет по всей папке школы.

## Голос и чат-бот (NeuralDeep)

- API-ключ задаётся при сборке через `local.properties` (`neuraldeep.apiKey=...`,
  файл не попадает в git) и меняется на экране Настройки.
- Чат-модель по умолчанию: `qwen3.8-flash-next-ru-noreason` (быстрая, русская,
  без задержки на reasoning). Доступны также `gpt-oss-20b/120b`, `qwen3.6/3.8`,
  `kimi-k2.6` и др.
- Распознавание: `whisper-1` через `/v1/audio/transcriptions` (проверено:
  WAV 16 кГц → текст за ~3 с; первый токен ответа ~0,6 с).
- ReSpeaker XVF3800 подключается по USB и определяется автоматически
  (`AudioRecord.setPreferredDevice`); без него используется встроенный микрофон.
  Запись с автоостановкой по паузе (~1,5 с), максимум 30 с.
- Альтернативы: локальный Whisper-сервер (faster-whisper-server и т.п.) или
  встроенный распознаватель Android; Ollama/OpenAI-совместимый чат на своём
  сервере (например `192.168.1.124`).

## Настройки

Экран «Настройки»: NAS (адрес, share, папка, пользователь/пароль, проверка
подключения), папки медиатеки (music/photo/books/school), чат-бот (адрес, тип
API, модель, ключ, системный промпт, проверка), распознавание речи (режим,
адрес, ключ), озвучка ответов.

## Сборка

JDK 17+, Android SDK (platform 35). Скопируйте `local.properties.example`
в `local.properties`, укажите `sdk.dir` и при необходимости `neuraldeep.apiKey`.

```bash
./gradlew :app:assembleRelease   # или assembleDebug
```

Gradle 8.14 (wrapper), AGP 8.13.2, Kotlin 2.2.21.

## Структура

```
app/src/main/java/com/homeprojector/launcher/
├── MainActivity.kt      # навигация, режим лаунчера
├── Prefs.kt             # настройки
├── ui/                  # экраны: Home, Nas, School, Music, Photos, Books,
│                        #   Reader, Files, Local, Apps, Voice, Chat, Downloads, Settings
├── nas/                 # SMB-клиент (jcifs-ng): листинг, поиск, DataSource для ExoPlayer
├── music/               # парсер тегов из заголовков, библиотека с кэшем, плеер-синглтон
├── books/               # кэш книг, позиции/закладки, парсеры EPUB/FB2/TXT
├── download/            # менеджер загрузок с паузой/докачкой
├── net/                 # ChatClient (Ollama/OpenAI SSE), SttClient (Whisper)
└── voice/               # запись с USB-микрофона, VAD, TTS, запасной Android STT
```

## Замечания

- HTTP к локальным серверам разрешён (`usesCleartextTraffic`); NeuralDeep по HTTPS.
- Кэши: превью изображений (LRU), страницы PDF (LRU + mutex), музыкальная
  библиотека (JSON на диске, перечитываются только изменённые файлы), книги
  (по SHA-1 URL, без коллизий имён).
- Проверено в эмуляторе (1920×1080, Android 16) с локальным SMB-сервером:
  все разделы, воспроизведение видео/музыки, читалки, фото, чат NeuralDeep.
